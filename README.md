# PIC Microcontroller Projects

This repository contains projects developed during my virtual internship with **Microchip**, using **8-bit PIC microcontrollers**.  
All projects are implemented in **MPLAB X IDE** with the **XC8 compiler**.

---

## 📂 Project List

### ✅ Completed
1. [Project1: LED Blink](Project1_LED_Blink/README.md)  
   - Simple GPIO and Timer0 interrupt example.  
   - Toggles an LED every 500ms.  

2. [Project2: UART Communication](Project2_UART_Communication/README.md)  
   - Demonstrates serial communication using UART.  
   - Sends/receives characters to/from a PC terminal.  

3. [Project3: ADC Temperature Sensor](Project3_ADC_Sensor/README.md)  
   - Reads analog data from LM35 temperature sensor using ADC.  
   - Sends converted temperature to PC via UART.  

---

### 🚧 In Progress
4. [Project4: PWM Motor Control](Project4_PWM_MotorControl/README.md)  
   - (Planned) Use PWM to control DC motor speed.  
   - Add encoder feedback for basic PID.  

5. [Project5: IoT Sensor Node](Project5_IoT_SensorNode/README.md)  
   - (Planned) Send sensor data via ESP32 + MQTT to cloud dashboard.  

---

## 🔹 Tools Used
- MPLAB X IDE  
- XC8 Compiler  
- PIC16F877A (8-bit microcontroller)  
- Proteus / Breadboard for circuit testing
